# IERMS™ Audit Scorecard v1.0
## Institutional Emergency Readiness Assessment Instrument

> **Purpose:** Objective 100-point evaluation tool for hospital baseline audits, 90-day pilot evaluations, and annual IERMS™ accreditation renewals.  
> **Auditor Role:** Conducted by Paeds Resus Clinical Quality Auditor in coordination with Hospital Quality Director & Chief Nursing Officer.

## 2. Accreditation Level Determination

- [ ] **Level 1: Unprepared / High Risk** (`< 50 Points`) — Immediate remediation required. Re-audit in 30 days.
- [ ] **Level 2: Baseline Functional** (`50 – 69 Points`) — Conditional approval. Action items required within 90 days.
- [ ] **Level 3: IERMS™ Certified** (`70 – 89 Points`) — Full Accreditation granted. Renewable annually.
- [ ] **Level 4: High-Reliability Exemplar** (`90 – 100 Points`) — Highest Distinction Accreditation. Recognized Regional Learning Center.

## 3. Detailed Audit Criteria (100 Points Total)

### Domain 1: Governance & ERT Activation (20 Points)

| Item Code | Evaluation Criterion | Max Pts | Score | Audit Method / Verification |
|-----------|----------------------|---------|-------|------------------------------|
| **D1.1** | Formal executive-signed Code Blue / Emergency Response Policy active. | 5 | | Document inspection & signature check |
| **D1.2** | 24/7 ERT Nurse Duty Roster published in all clinical departments. | 5 | | Spot-check current shift duty roster |
| **D1.3** | Cross-unit activation pathway functional (tested via drill/simulation). | 5 | | Unannounced mock code drill response time |
| **D1.4** | First qualified responder arrives at scene in `< 3 minutes`. | 5 | | Mock drill stopwatch measurement |

---

### Domain 2: Bedside Guidance & ResusGPS Utilization (20 Points)

| Item Code | Evaluation Criterion | Max Pts | Score | Audit Method / Verification |
|-----------|----------------------|---------|-------|------------------------------|
| **D2.1** | Dedicated mobile/tablet device with ResusGPS present in key units (ER, Paeds, NBU, ICU). | 5 | | Physical device inspection |
| **D2.2** | ResusGPS running PWA offline mode verified on all devices. | 5 | | Disconnect Wi-Fi/cellular & test app load |
| **D2.3** | Staff demonstrate proficient weight-based dosing calculation during spot audit. | 5 | | Spot-audit 3 nurses on weight calculation |
| **D2.4** | ResusGPS CPR Clock used in >80% of documented code responses. | 5 | | Sample last 10 code debrief records |

---

### Domain 3: Safety Culture & Care Signal QI (20 Points)

| Item Code | Evaluation Criterion | Max Pts | Score | Audit Method / Verification |
|-----------|----------------------|---------|-------|------------------------------|
| **D3.1** | Care Signal incident reporting active with >5 reports logged per month. | 5 | | Institutional dashboard analytics review |
| **D3.2** | Monthly Quality Improvement (QI) Committee meetings documented with minutes. | 5 | | Review last 3 months QI committee minutes |
| **D3.3** | System gap action items (FPKB) closed within 30 days of logging. | 5 | | Care Signal action log verification |
| **D3.4** | Non-punitive reporting policy communicated and acknowledged by clinical staff. | 5 | | Staff interview sample (5 clinical staff) |

---

### Domain 4: Workforce Training & Competency Mesh (20 Points)

| Item Code | Evaluation Criterion | Max Pts | Score | Audit Method / Verification |
|-----------|----------------------|---------|-------|------------------------------|
| **4.1** | `> 75%` of ER & Paediatric clinical staff actively enrolled in role-mapped training mesh. | 5 | | Platform training coverage rollup |
| **4.2** | `> 60%` of target staff hold valid AHA-aligned BLS & PALS/ACLS credentials. | 5 | | Certification registry audit |
| **4.3** | Strict BLS-before-ACLS/PALS prerequisite compliance verified platform-wide. | 5 | | System credential check (zero bypasses) |
| **4.4** | Facility has at least 1 certified internal Instructor (Provisional/Qualified/Lead). | 5 | | Instructor registry verification |

---

### Domain 5: Physical Readiness & Equipment Audits (20 Points)

| Item Code | Evaluation Criterion | Max Pts | Score | Audit Method / Verification |
|-----------|----------------------|---------|-------|------------------------------|
| **D5.1** | Standardized Crash Cart layout & Broselow/weight-based organisation across all wards. | 5 | | Inspection of 3 ward crash carts |
| **D5.2** | 100% availability of paediatric airways (ETTs 2.5-6.5, Guedel 00-3, BVMs infant/paed). | 5 | | Complete physical inventory count |
| **D5.3** | Functional paediatric defibrillator with paediatric pads/attenuator present & tested. | 5 | | Battery check & pad expiration audit |
| **D5.4** | Daily shift-by-shift crash cart checklist compliance `> 90%` over past 30 days. | 5 | | Audit physical/digital daily log sheets |
