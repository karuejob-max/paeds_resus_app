## 1. Institutional Dashboard Telemetry

Hospital Admin Dashboard (`/hospital-admin-dashboard`) surfaces real-time telemetry:
- ERT activation counts & time-to-response (< 3 min target).
- Paediatric activation ratio.
- Training coverage rollup (>75% target).
- Open equipment/system fixes.

---

## 2. Accreditation Data Integrity

Dashboard analytics feed the annual IERMS™ re-accreditation scorecard evaluation.
