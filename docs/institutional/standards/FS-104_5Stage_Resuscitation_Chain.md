## 1. The 5-Stage Continuum

Every emergency clinical workflow must enforce the 5-stage resuscitation continuum to ensure survival and continuous system learning:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        5-STAGE CLINICAL RESUSCITATION CHAIN                            │
├───────────────┬───────────────┬───────────────┬───────────────────┬────────────────────┤
│ 1. Recognition│ 2. Activation │ 3. Response   │ 4. Stabilization  │ 5. Recovery        │
│ Early warning │ Instant Code  │ ERT arrival   │ Bedside ResusGPS  │ Post-ROSC care,    │
│ signs & vitals│ Blue/Yellow   │ < 3 minutes   │ ABCDE flow & CPR  │ GAS debrief, Care  │
│ monitoring    │ signal        │ hospital-wide │ clock dosing      │ Signal incident log│
└───────────────┴───────────────┴───────────────┴───────────────────┴────────────────────┘
```

## 2. Stage Breakdown

### Stage 1: Recognition
- **Indicator:** Physiological early warning score deterioration (spO2 < 90%, capillary refill > 3s, gasping/absent breathing, altered AVPU).
- **Tool:** Routine vital sign monitoring and bedside awareness.

### Stage 2: Activation
- **Indicator:** Immediate shouting for help and triggering central hospital Code Blue (arrest) or Code Yellow (pre-arrest).
- **Target:** Activation completed in `< 30 seconds` of recognition.

### Stage 3: Response
- **Indicator:** ERT primary responders and ERTL mobilize across wards.
- **Target:** First qualified responder at scene in `< 3 minutes`.

### Stage 4: Stabilization
- **Indicator:** High-quality CPR, airway management, fluid resuscitation, and weight-dosing guided by **ResusGPS** PWA.
- **Target:** ROSC or return of physiological stability.

### Stage 5: Recovery & Learning
- **Indicator:** Post-ROSC critical care transfer, 5-minute team GAS debrief, and Care Signal near-miss submission to feed the Failure Pattern Knowledge Base (FPKB).
