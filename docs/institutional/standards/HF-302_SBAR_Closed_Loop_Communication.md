## 1. Closed-Loop Communication Protocol

During Code Blue / Yellow resuscitation:
1. **Order:** Team Leader directs order to a named person ("Nurse Mary, give 0.15 mg Epinephrine IV").
2. **Repeat-Back:** Receiver repeats order ("Giving 0.15 mg Epinephrine IV now").
3. **Confirmation:** Team Leader confirms ("Correct").
4. **Completion Call-Out:** Receiver announces completion ("0.15 mg Epinephrine IV administered").

---

## 2. Structured Handover (SBAR)

All patient handovers (shift change, ward-to-ICU transfer) must follow **SBAR**:
- **S (Situation):** Patient name, age, primary emergency condition.
- **B (Background):** Admission history, key clinical context.
- **A (Assessment):** Current vitals, ABCDE status, ResusGPS interventions.
- **R (Recommendation):** Pending actions, monitoring requirements.
