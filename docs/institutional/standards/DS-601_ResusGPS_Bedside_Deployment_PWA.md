# DS-601: ResusGPS Point-of-Care Bedside Deployment Standard

> **Series:** Digital Standards (DS)  
> **Status:** Official Standard v1.0 — July 2026  
> **Governance:** Paeds Resus Clinical Stewardship Committee

## 1. Bedside Hardware & Offline PWA Setup

ResusGPS deployed on dedicated ward tablets / verified mobile devices running offline-capable PWA to guarantee guidance during network downtime.

---

## 2. Core Bedside Features

- Weight-based drug & fluid dosing calculator.
- Structured ABCDE assessment flows.
- Visual CPR Clock (2-min cycle prompts, epinephrine timer).
